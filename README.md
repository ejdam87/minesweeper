# Minesweeper
This is a simple terminal-based implementation of classic game of minesweeper.

## How to use it
At each round, you make a move by the following input: `m x y`, where:
- `m` is one of the f, r, d (flag, reveal, debug)
- `x y`are the coordinates of the cell to interact with
